There are several ways to extract plain text from a PDF document. Here are a few methods you can try:

### 1. **Using Online Tools**
- **PDF to TEXT Converter**: Websites like [FreeConvert.com](https://www.freeconvert.com/pdf-to-text) and [PDF Candy](https://pdfcandy.com/extract-text.html) allow you to upload your PDF and convert it to a text file directly in your browser⁴⁵.

### 2. **Using Software**
- **Adobe Acrobat Reader**: Open your PDF in Acrobat Reader, use the "Selection Tool" to highlight the text, right-click, and select "Copy"⁶.
- **Icecream PDF Editor**: Download and install the software, open your PDF, go to the "Edit" tab, and use the "Select" tool to highlight and copy the text⁸.

### 3. **Using OCR (Optical Character Recognition) Tools**
- **Smallpdf**: This tool can convert scanned PDFs into readable text using OCR. Upload your PDF, let the tool process it, and then copy the text from the new PDF⁷.

### 4. **Using Programming Libraries**
- **Python**: Libraries like `PyPDF2` or `pdfminer.six` can be used to extract text programmatically. Here's a simple example using `PyPDF2`:

```python
import PyPDF2

# Open the PDF file
with open('example.pdf', 'rb') as file:
    reader = PyPDF2.PdfFileReader(file)
    text = ''
    for page in range(reader.numPages):
        text += reader.getPage(page).extract_text()

print(text)
```
