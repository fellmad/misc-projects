Sure! Here's a simple "Hello, World!" program in TypeScript:

1. **Create a new TypeScript file** called `app.ts` and add the following code:
```typescript
let message: string = 'Hello, World!';
console.log(message);
```
2. **Compile the TypeScript file** to JavaScript using the TypeScript compiler (`tsc`). Open your terminal and run:
```bash
tsc app.ts
```
This will generate a file named `app.js`.
3. **Run the JavaScript file** using Node.js:
```bash
node app.js
```

You should see the output:
```
Hello, World!
```

If you want to run the TypeScript file directly without compiling it first, you can use the `ts-node` package. Install it using npm:
```bash
npm install -g ts-node
```

Then run your TypeScript file:
```bash
ts-node app.ts
```

This will also output:
```
Hello, World!
```
